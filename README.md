# 初中数学班主任工作台

面向民办初中数学教师兼班主任的本地优先个人工作台。打开首页即可看到本周课表、今日待办和校历，拖动即可完成调课。

依据 `teacher-platform/docs/` 下的[开发文档](../teacher-platform/docs/初中数学班主任工作台开发文档.md)与[UI 执行规范](../teacher-platform/docs/UI-SPEC-初中数学班主任工作台.md)从零实现。

## 技术栈

React 18 · TypeScript · Vite 5 · Tailwind CSS 3 · Dexie (IndexedDB) · dnd-kit · lucide-react

## 运行

```bash
npm install
npm run dev      # http://localhost:5180
npm run build    # 类型检查 + 产物构建
npm run preview
```

首次启动自动写入示例数据（初二（3）班、初二（5）班，含课程、学生、待办、校历、成绩等），可在「数据与设置 → 重置为示例数据 / 清空全部数据」管理。

## 功能总览（P0 已完成）

- **首页工作台**：日期标尺（教学周次 / 单双周 / 当前时间）、本周课表、今日待办（逾期 / 今天 / 本周）、迷你校历与事项倒计时、班务提醒条（请假 / 待跟进沟通 / 待批改作业）。
- **可拖动课表**：拖动课程卡 → 锚定弹层选择「仅本周 / 从本周起」；目标有课时可交换或二次确认覆盖；原位置显示虚线占位；Toast 5 秒内可撤销；键盘用户可按 M 进入移动模式后点击目标格。同一课程支持连续多次临时调课。
- **待办**：分组、分类筛选、批量操作、更多信息折叠。
- **校历**：月历（每格最多 3 项）、事项抽屉、首页倒计时。
- **班级管理**：顶栏与课表区均可添加 / 切换 / 删除班级；有关联数据时只能归档；至少保留一个班级。
- **学生与家长**：最小字段表格、电话部分隐藏、敏感备注仅详情可见、CSV 粘贴导入。
- **出勤与请假**：名单默认正常只记异常、请假记录含家长确认与进行中状态。
- **数学成绩**：考试管理、录入、平均分 / 中位数 / 及格率 / 优秀率、品牌蓝趋势折线与文字摘要。
- **备课资料 / 作业记录 / 座位与值日 / 家校沟通 / 班级记录 / 常用文档**：对应 P1 的轻量实现。
- **数据与设置**：JSON 全量备份与恢复（先预览后覆盖）、清空数据、重置示例数据、访问密码锁（SHA-256，仅访问保护）、学期 / 节次设置。
- **响应式**：桌面侧栏可收起；<768px 切换为底部导航 + 当天课程列表；打印输出黑白课表与座位表。

## 设计规范

- 品牌色 Yves Klein Blue `#002FA7`（当前态 / 主按钮 / 今天 / 焦点），唯一强调色。
- 表面仅白色与冷中性灰，细边框 + 留白 + 极轻阴影；圆角：输入 14px、菜单 12px、分组 18px、功能卡 22px、面板 24px、总览 26px、按钮胶囊 999px。
- 课程色板仅用于课表数据编码，同一课名恒定同色，未知课名使用稳定备用色。
- 日期、节次、成绩使用等宽字体（`tabular-nums`）；内容块按 50–60ms 间隔依次进入；遵循 `prefers-reduced-motion`。

## 目录结构

```
src/
├── components/        # Layout 外壳、ui 基础组件、班级管理、快速记录
│   ├── timetable/     # WeekGrid 周课表（拖动/移动模式）、CourseCard、MoveScopePopover、CourseEditor
│   ├── todos/         # TodoSummary 首页待办、TodoDrawer
│   ├── calendar/      # MiniCalendar、EventDrawer
│   └── dashboard/     # DateRail 日期标尺
├── contexts/          # ToastContext、ClassContext（当前班级共享状态）
├── db/                # Dexie Schema（P0 + P1 全部表）与示例数据
├── lib/               # 周次计算、课表叠加纯函数、课程色板、备份、CSV、密码哈希
├── pages/             # 14 个页面路由
└── services/          # 调课写入服务（仅本周 / 长期 / 交换 / 覆盖，均支持撤销回滚）
```

## 数据说明

- 全部数据保存在本机 IndexedDB（数据库名 `teacher-workbench`），不上传任何学生数据。
- 基础课表（`courseTemplates`）与临时调课（`courseAdjustments`）分表存储；展示某周课表时按记录创建顺序链式叠加，撤销只回滚对应记录。
- 备份为完整 JSON（业务表 + 设置），恢复前展示各表记录数预览，高风险操作均需确认。
