# 分享给其他电脑：自签名证书安装说明

本说明适用于 `初中数学班主任工作台 0.1.0` 的熟人、校内或小范围内部分享。

## 需要发送的文件

1. `初中数学班主任工作台-0.1.0-Windows-x64.exe`
2. `初中数学班主任工作台-自签名公钥证书.cer`

不要发送或索要私钥。本项目的签名私钥不可导出，只保存在制作者当前 Windows 用户的证书库中。

## 接收方先核对

- 证书主题：`CN=初中数学班主任工作台 自用签名`
- 证书指纹（SHA-1）：`FD99E4F984A6695DD23ACC8AD4F90C60B4BAFB79`
- EXE 的 SHA-256：`5998369A7E024D9EC4D79D5B0CA5D87B6C291C52FB53AD83A6D2BB6F90CF5C51`
- CER 文件的 SHA-256：`7C99B268722AEF08C69CAC6F306FDC336DD131C3378685E835BF99779C55190C`

请通过可信渠道另行确认上述指纹。指纹不一致时，不要运行程序或安装证书。

## 在另一台 Windows 电脑建立信任

以下操作只选择“当前用户”，不要选择“本地计算机”。

1. 双击 `.cer` 文件，点击“安装证书”。
2. 选择“当前用户”。
3. 选择“将所有的证书都放入下列存储”，把证书安装到“受信任的根证书颁发机构”。
4. 再次双击同一个 `.cer` 文件，重复安装一次，这次选择“受信任的发布者”。
5. 右键 EXE，打开“属性 → 数字签名”，确认签名者为“初中数学班主任工作台 自用签名”，签名状态有效。
6. 双击运行 EXE。SmartScreen 的应用信誉判断和证书信任是两套机制，首次下载仍可能出现提醒；确认指纹和数字签名无误后再运行。

## 撤销信任

按 `Win + R`，输入 `certmgr.msc`，分别在以下两个位置删除“初中数学班主任工作台 自用签名”：

- 受信任的根证书颁发机构 → 证书
- 受信任的发布者 → 证书

## 面向陌生用户公开发布

自签名证书不适合大规模公开分发。若项目完整开源、使用 OSI 认可许可证并满足维护、发布和可验证构建等条件，可以申请 SignPath Foundation 的免费开源代码签名；否则应使用受公众信任的 OV/EV 或 Azure Trusted Signing。
